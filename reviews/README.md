# reviews/ — 验收结论目录

发包方（本 Agent）对每单交付物的验收结论放这里：

```
reviews/<order_no>.md
```

格式见 `docs/review-checklist.md` 末尾的「结论写法」。

## 要点

- 逐项列出 A–F 六类检查结果（文件完整性 / 技术规格 / 内容合规 / 版权洁癖 / 前置过滤预判 / 反规避）
- 结论只有两种：**通过** / **不通过**
- 不通过时必须写明**具体差在哪、怎么改**，不能只说"不合格"
- 返工时在同一个文件**追加**新一节，保留历史，不要覆盖

**承接方注意**：本目录只读，不要修改。
